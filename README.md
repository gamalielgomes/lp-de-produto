# 🎵 Zingen - Landing Page Responsiva

Projeto desenvolvido com o objetivo de praticar e aprimorar conceitos de **responsividade utilizando HTML e CSS**.

A página consiste em uma landing page para um aplicativo fictício de música chamado **Zingen**, com foco na adaptação da interface para diferentes tamanhos de tela.

## 🚀 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de desenvolvimento web, com foco principalmente em:

- Estruturação de páginas com HTML
- Estilização utilizando CSS
- Desenvolvimento de layouts responsivos
- Uso de Media Queries
- Flexbox
- Organização e reutilização de estilos
- Adaptação de elementos para diferentes tamanhos de tela
- Boas práticas de organização de código

O projeto foi construído utilizando **somente HTML e CSS**, sem JavaScript ou frameworks.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📱 Responsividade

Um dos principais objetivos deste projeto foi trabalhar a adaptação da interface para diferentes dispositivos.
Pensando primeiro na experiencia mobile e depois desktop.

Foram utilizados conceitos como:

```css
@media (width >= 80em) {
  /* estilos para dispositivos desktop */
}
```

Dessa forma, elementos como navegação, textos, botões e espaçamentos podem se adaptar de acordo com a largura da tela.
